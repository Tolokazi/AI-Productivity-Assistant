Installation

Clone the repository:

git clone <repository-url>

Navigate to the project directory:

cd project-name

Install dependencies:

npm install

Configure environment variables:

DB_HOST=localhost
DB_USER=username
DB_PASSWORD=password
PORT=3000

Start the application:

npm start

Open your browser and visit:

http://localhost:3000
